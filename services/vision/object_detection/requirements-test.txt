# GPU-free test path for the inference server.
#
# torch, ultralytics and opencv are deliberately ABSENT: server/runtime.py keeps
# torch behind a lazy import and engine.py imports ultralytics/cv2/numpy only
# inside load()/infer(), so the protocol, HTTP and WebSocket layers are fully
# importable and testable on a machine with no GPU and no 2.5 GB torch install.
# The tests that would need a real model mock engine.infer instead.
#
#   cd services/vision/object_detection
#   python -m venv .venv-test && .venv-test\Scripts\activate
#   pip install -r requirements-test.txt
#   cd ../..            # run from services/ so the `vision` package resolves
#   python -m pytest vision/object_detection/tests
#
# For the real CUDA server use requirements.txt instead (it is a superset).
