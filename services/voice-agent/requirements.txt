# (gemini-embedding-001) — no extra core deps.
# pypdf is optional and only needed to index PDF files dropped into knowledge/:
#   python -m pip install pypdf

# Target-speaker gating ("ignore bystander chatter") is optional and off by
# default (speaker_gate_enabled in config/api_keys.json). Enabling it needs a
# voice encoder; without it the agent streams all awake audio exactly as before:
#   python -m pip install resemblyzer   # pulls in torch (CPU is fine)
#   python -m pip install "setuptools<81"  # resemblyzer's webrtcvad dep still
#       # imports pkg_resources, which setuptools 81+ no longer bundles —
#       # without this pin, `from core import speaker` fails at import time
#       # and the gate silently stays disabled.

# Experimental GPU target-speaker EXTRACTION (core/target_speaker_gpu.py,
# 2026-09-22 research spike) is a separate opt-in on top of the above:
# speaker_extraction_backend: "gpu_separation_experimental" in
# config/api_keys.json (default is "resemblyzer" — unaffected unless you
# change this). Needs a CUDA build of torch (this replaces the CPU torch
# resemblyzer pulled in above) plus speechbrain for the pretrained
# speechbrain/sepformer-wsj02mix separation model:
#   python -m pip install --index-url https://download.pytorch.org/whl/cu128 torch
#   python -m pip install speechbrain
# See bench/gpu_extraction_bench.py for standalone latency/RTF numbers
# before turning this on, and core/target_speaker_gpu.py's module docstring
# for why this is separation+selection rather than a truly
# target-conditioned model — no pip-installable, quality-verified,
# pretrained target-speaker-conditioned checkpoint exists as of this
# writing. Any CUDA/model failure falls back to the Resemblyzer gate above,
# per-chunk, automatically.
